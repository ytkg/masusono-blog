# 本棚ミニアプリ

「その他」から起動し、その都度公開記事全件（既存microCMS全件取得保護の範囲内）とopenBD書誌を取得する。公開APIを使うため下書きや公開停止記事は含まない。ISBN-10チェック数字が有効なAmazon商品リンクだけをISBN-13に変換する。短縮URL展開、本文変更、永続保存、別サービスでの書誌補完は行わない。

openBDは100冊単位・同時1接続、各リクエスト最大5秒（接続3秒）、書誌処理全体20秒。失敗後の追加バッチ・自動再試行は行わない。取得済みの本があれば部分表示、失敗して表示可能な本がなければ共通APIエラー。正常未収録と障害は区別する。ブラウザは最大60秒で中断し、終了時も中断する。

Google Booksは詳細を開く時だけISBN検索し、ISBN識別子一致、非電子版、Googleの画像・詳細URLを確認する。同じ起動中は成功・失敗ともメモリ上で共有する。表紙照会は同じ起動中に1接続ずつ行い、画像取得は5秒（接続3秒）まで。失敗・画像なしでも書誌と記事リンクは使用できる。Googleが429を返した場合は503としてクライアントへ通知し、その起動中の追加表紙照会を止める。表紙はGoogle Booksのリンクと帰属表示を添え、加工せず縦横比を維持する。

## 公開前の運用設定

既存のRails非公開credentialsに `google_books.api_key` と `google_books.removal_contact_url`（権利者が削除依頼を送れる公開HTTPS URL）を設定した場合だけ表紙照会を有効にする。キーはBooks APIとサーバーの実行環境に適切に制限する。キーや連絡先の発行・本番設定はこのPRでは行わない。両方が未設定でも本棚・書誌・記事リンクは使える。

調査時点でサイト内に削除依頼用の公開窓口は確認できなかった。**オーナーによる窓口の決定と公開は、Google Books表紙の公開前に解決する未完了の運用事項**。設定には実際に連絡可能なページを使うこと。権利者またはGoogleから削除依頼が来たら即時対応し、必要なら表紙設定を無効化する。

Google Books API有効化・制限済みキー設定後の実照会は運用側で確認する。単に表紙が返らない本を合格条件から除外しない。

参照（2026-10-21確認）：[openBD仕様・利用条件](https://openbd.jp/)、[Google Books表示ガイド](https://developers.google.com/books/branding)、[利用規約・削除要件](https://developers.google.com/books/terms)、[API利用方法](https://developers.google.com/books/docs/v1/using)。
