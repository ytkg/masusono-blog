# 増田スロット「増田の野望」

Issue #816 のフェーズ1。`/others` のランチャーから起動するフロントエンド内のゲーム。
サイト共通ヘッダーを残した全画面表示で、Ads・API・サーバー保存は使わない。
閉じて開き直す・ページ移動・再読み込みで1,000ptに戻る。
非表示・アプリ非アクティブ・説明表示中はリールとオート消化を止め、状態を保つ。

## 抽選と状態遷移

- 通常は3pt掛け。BIG 1/320、REG 3/1600。レバー時にボーナス、小役の順に独立抽選する。
- 小役は重複しない区間抽選で、ベル1/6・チェリー1/64・スイカ1/64・リプレイ1/7。
- 同時に当選した場合も含め、ボーナス入賞待ちは小役優先。小役を取りこぼしてもそのゲームにボーナスを入賞させない。
- ボーナスは入賞まで持ち越し、再抽選しない。「野望！」で当選だけを告知する。
- BIGは7・7・7、REGは7・7・BAR。入賞ゲームの賭けは通常の3pt、リプレイ後なら0pt。入賞そのものの払い出しは0pt。
- ベル8pt・チェリー2pt・スイカ6pt。リプレイは払い出し0ptで次の賭けを無料にする。重複ラインでの増額はしない。
- BIG中は1pt掛け・ベル9pt、累計342pt以上で終了。全取得なら38ゲーム・純増304pt。
- REG中は1pt掛け・ベル8pt、累計120pt以上で終了。全取得なら15ゲーム・純増105pt。
- ボーナス中は毎ゲームベル当選。手動・解除可能なオート消化を選べる。最終払い出しは全額加算する。
- 毎回のボーナス終了後に野望タイム50ゲーム。BIG 1/50・REG 1/75。リプレイも1ゲームとして数える。
- 50ゲーム目も高確率で抽選する。当選時に残り回数を終了し、次のボーナス終了後に50へ戻す。
- 賭け不足でゲームオーバー。無料リプレイがあれば先に遊べる。ボーナス入賞の救済は設けない。

## リールと停止表

配列・有効ライン・停止表の生成は
`app/frontend/features/apps/masudaSlot/reels.js` に集約する。
3リール各21コマ、上向きに約0.8秒で1周。中央位置に対して上・中・下の3コマを表示する。
有効ラインは横3本と斜め2本。チェリーは左リールのどの行でも有効。
配列全体はゲーム内の「遊び方・配列表」にも表示する。

`stopTable(role)` が役ごとに `(21 + 1)^3 = 10,648` 状態の停止表を生成・キャッシュする。
`-1` は未停止で、完成状態は「当選役だけが成立」または「すべて不成立」の場合だけ合法。
複数の異なる役の同時成立も禁止し、非当選役の誤入賞を防ぐ。

部分停止状態は、残りリールのどちらを次に押しても、すべての押下位置から0〜4コマ先に
合法な停止経路が残る場合に限って安全とする。安全な候補の中で当選役への到達可能性を優先し、
同点は引き込みが短い候補を採用する。チェリー・スイカ・ボーナスは取りこぼし得る。

`reels.test.js` は7役すべてで全停止表・残りリール・21押下位置を検証する。
任意押し順で最後まで合法な候補が存在し、引き込みが0〜4コマであることを確かめる。
別途、5ライン・チェリーの3行・払い出しの重複排除を検証する。

## 収支試算

再実行はリポジトリルートから `node scripts/simulate-masuda-slot.mjs`。
ゲーム本体と同じ抽選・停止・精算を使い、seed=816の乱数列で各2,000セッション、
1,000pt開始・最大5,000ゲーム・破産時終了として試算する。通常・入賞待ち・ボーナス・野望タイムをすべて含む。
押し順は左→中→右で固定し、他の押し順の合法性は網羅テストで別に保証する。

- 無作為：各リールの押下位置が一様ランダム。ボーナス中も同じ。
- 目押しあり：内部役を見ず、通常時はチェリー／スイカの位置を狙い分ける。告知後は7を狙い、右だけ7／BARを切り替える。75%は狙った位置、25%は±3コマの誤差。ボーナス中は無作為。
- 理論上限：内部役を既知として、全役が入賞可能な位置を選ぶ。実際のプレイヤーに内部役を表示する機能ではない。

| 指標 | 無作為 | 目押しあり | 理論上限 |
| --- | ---: | ---: | ---: |
| 5,000Gまたは破産までの平均収支 | +6,664pt | +7,711pt | +8,161pt |
| 同収支の中央値 | +6,775pt | +7,939pt | +8,267pt |
| 同収支の下位10%点 | +3,457pt | +4,292pt | +4,549pt |
| 最初の500Gまたは破産までの平均収支 | +454pt | +539pt | +619pt |
| 500G時点（破産時は終了時）で収支−500pt以下の割合 | 9.40% | 8.70% | 6.70% |
| 5,000G以内の破産率 | 4.15% | 2.45% | 2.45% |
| 終了時プラスの割合 | 95.75% | 97.50% | 97.55% |
| 最大ドローダウンの90%点 | 1,232pt | 1,199pt | 1,107pt |
| ボーナス1回あたり入賞待ちG（当選Gを含む） | 9.70 | 3.31 | 1.52 |
| チェリー取得率 | 33.52% | 75.78% | 100% |
| スイカ取得率 | 2.27% | 22.67% | 100% |

この試算のボーナスは全モデルでBIG平均38G・純増304pt、REG平均15G・純増105pt。
払い出し基準と賭けの検証は状態遷移テストでも行う。

野望タイム50Gでの再当選率は `1 - (29/30)^50 ≈ 81.64%`。
合意どおり強い連チャン性能を維持し、小役確率の調整は行っていない。
長く遊ぶと増えやすい一方、短期の500pt以上の負けや破産も発生する。
試算は操作モデルと有限標本による見積もりで、実機タッチの反応や人間の上達曲線は再現しない。
モデル間で乱数列の区間が異なるため、破産率などの大小関係を保証するものではない。

## 検証

- React：残高、キーボード、非表示・非アクティブ時の停止、ボーナス種別の非表示、オート消化と終了、説明表示、アンマウント後の初期化。
- Playwright：PC・スマホ・320×568、共通ヘッダーと全画面表示、実リールの停止、説明、閉じて再起動。
