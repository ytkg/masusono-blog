# 強欲は身を滅ぼす？ 初期バランス検証

仕様は Issue #733 の承認済みルールをそのまま使用。価格・確率式・CPU範囲の変更なし。

## 読み取り

代表条件では最低100円より1,000〜2,000円の期待収支が高く、最低額だけが有利な設計ではない。一方、6,000〜10,000円は期待収支が負で、高額購入を繰り返すと大幅なマイナスになりやすい。高額でも3ラウンドすべて奢ってもらえば大きい記録を狙えるため、期待値重視と最高記録狙いで判断が分かれる。

例：CPU2,000円・6,000円、自分10,000円では1回の支払確率71.43%、3回とも奢ってもらう確率約2.33%。この分散と不利さは初期仕様によるもの。自動バランス調整・記録リセットは設けない。確率式・価格・CPU範囲を変更する場合はオーナー判断が必要。

確率と手合わせのテストでは代表金額4組×自分の手3種×6,000ラウンドを検証する。最終支払者を先に抽選し、各手合わせはその人が勝ち残る合法な組合せから生成する。あいこや2人決戦では支払者を抽選し直さない。

## 試遊

2026-10-20、専用環境をブラウザで操作し、乱数を固定せず3ラウンド完走した。
1ラウンド目は2,700円を選び、CPU2が奢って+2,700円。
2ラウンド目は8,000円を選び（奢ってもらえる表示43.04%）、3人あいこ→自分とCPU2の決戦→2人あいこ→自分が勝ち残り、全員分16,480円を減算。
3ラウンド目は100円でCPU2に奢ってもらい、最終−13,680円を初回自己ベストとして表示した。
CPUの買い直し、自分のカゴ初期化、手の選び直し、支払額と合計の一致を確認した。

試遊では中額・高額・少額の結果の振れを確認できたが、長期的な遊びやすさはこの1ゲームだけで断定しない。初版のルール変更は提案せず、公開後の試遊結果に応じてオーナーが判断する。
